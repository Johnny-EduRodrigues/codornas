# Backend

## Run the application

Simplest execution (be in 02_src/back$):

```bash
uv run goback
```

If you are in the repository root (sirahyl$), start the Flask development server like this:

```bash
uv run --project 02_src/back start-app
```

The app will be available at <http://127.0.0.1:5000>. Stop the server with
`Ctrl+C`.
